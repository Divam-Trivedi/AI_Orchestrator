AI Orchestrator Documentation

Architecture at a Glance

The AI Orchestrator is a self‑hosted, multi‑provider AI frontend built with FastAPI (Python) and a vanilla JavaScript UI. It acts as a middleware between the user and various LLM providers (OpenAI, Anthropic, Ollama, DeepSeek, Gemini), adding advanced features like context windowing, web search, and system prompts.

Backend (FastAPI)

  • Provider pool – single ProviderPool class reuses HTTP connections via httpx. Each provider (OpenAI, Anthropic, Ollama, DeepSeek, Gemini) implements the BaseProvider interface.
  • Database – SQLite (WAL mode) via database.py. Tables: settings, conversations, messages, system_prompts, groups.
  • Endpoints – RESTful routes for chat (/chat), history, settings, system prompts, group management, web search, health, and voice transcription.
  • Streaming – Chat responses are streamed using StreamingResponse with async generators, supporting real‑time token display.
  • Context window control – Three modes: all, last_n, first_m_last_n. Applied server‑side before sending to the LLM.
  • Web search – DuckDuckGo integration via /search endpoint injects results into the last user message.
  • Vision – Detects vision‑capable models and formats images per provider spec.
  • Voice – New /voice-models and /voice/transcribe endpoints. Supports OpenAI Whisper and browser Web Speech API.

Frontend (Vanilla JS + Tailwind)

  • Dynamic UI – Conversations, groups, model selector, token bar, context preview, system prompt presets.
  • Rich rendering – Markdown (marked.js), code highlighting (highlight.js), KaTeX for math.
  • File support – Drag & drop images/text/PDF; PDF extraction with pdf.js.
  • Mic button – Speech‑to‑text via browser or backend Whisper, with right‑click model selector.
  • Modular tabs – “More” hub can open external pages like this documentation using modular routing.

Key Files

  • main.py – server, routes, startup
  • providers.py – LLM provider classes + transcription
  • database.py – SQLite operations
  • static/index.html – main UI
  • static/script.js – main logic
  • static/SpeechToText.js – voice input module
  • static/style.css – custom styles

What is this?

This application lets you chat with different AI models (like ChatGPT, Claude, Gemini, and more) from one single place. You control your own API keys, so you pay only for what you use, and your data stays on your machine.

How to Get Started

1. Get an API Key

API keys are like passwords that let the app talk to the AI provider. Here’s how to get them from popular services:

  • OpenAI – Go to platform.openai.com/api-keys, create a new key, and copy it.
  • Anthropic (Claude) – Visit console.anthropic.com/keys and generate a key.
  • DeepSeek – Go to platform.deepseek.com/api_keys and create one.
  • Google Gemini – Obtain a key from Google AI Studio.
  • Ollama (local) – No API key needed; just install Ollama and make sure it’s running on http://localhost:11434.

What’s an API? Think of it as a waiter: you send a request (your message) to the provider’s kitchen, and the API brings back the AI’s reply. The API key is your ID card that allows you to enter.

2. Add Your Key to the App

  1. Click the ⚙️ API Keys Control button in the left sidebar.
  2. Click + Add Provider and choose the provider (e.g., OpenAI).
  3. Paste your API key into the API Key / Endpoint field.
  4. Add models you want to use (e.g., gpt-4o, gpt-4o-mini).
  5. (Optional) Add voice models like whisper-1 to enable speech‑to‑text.
  6. Click Save Configuration.

3. Start Chatting

  • Select a model from the dropdown at the top.
  • Type your message and press Enter (or click the send button).
  • To use voice input, click the 🎤 mic button near the input area. Right‑click it to choose the speech‑to‑text method.
  • Attach images or PDFs by dragging them into the text box or using the paperclip button.
  • Toggle Web Search (🔍) to let the AI see recent web results.
  • Adjust the context window size to control how much chat history is sent.
  • Pick a System Prompt (like “Programmer” or “Teacher”) from the Behavior menu to change how the AI responds.

Costs & Privacy

You pay only for what you use. Each provider charges a small amount per token (roughly a few cents per thousand words). All processing happens via your own API key, so the providers see your messages, not us. Your chat history stays locally on your computer in a database file (chat_history.db).

To estimate cost:

  • OpenAI: ~$0.01–0.03 per message with GPT‑4o.
  • Anthropic: similar pricing for Claude.
  • DeepSeek: significantly cheaper (~$0.001 per message).
  • Ollama: free (runs on your own hardware).

Grouping Conversations

  • Click + Create Group in the sidebar to organise chats.
  • Drag & drop chats into groups by right‑clicking a conversation and selecting a group.
  • Rename or delete groups via the same menu.

Custom System Prompts

You can create your own AI behaviour presets (like “Lawyer”, “Doctor”) from the Behavior menu. These are saved locally and only affect your prompt style.
